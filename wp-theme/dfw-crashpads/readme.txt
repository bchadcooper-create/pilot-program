=== DFW Crashpads ===
Requires at least: 6.0
Tested up to: 6.7
Requires PHP: 7.4
License: GPLv2 or later

Conversion-focused theme for the DFW Crashpads website.

Install: Appearance > Themes > Add New > Upload Theme > choose dfw-crashpads.zip > Activate.
Then install and activate the DFW Crashpads Core plugin (dfw-crashpads-core.zip) for the application form.
Edit everything under Appearance > Customize > DFW Crashpads.
The theme draws the homepage itself, so no homepage setup is needed.
